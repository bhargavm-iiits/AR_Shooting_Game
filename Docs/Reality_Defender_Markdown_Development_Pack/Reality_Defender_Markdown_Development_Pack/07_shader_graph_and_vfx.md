# 07 — Shader Graph and VFX

## 1. Visual goal

Targets should look volatile or energy-filled. The assignment explicitly disallows standard Unity materials for targets and asks for a custom Shader Graph using one or more of:
- Scrolling noise texture.
- Fresnel rim light.
- Vertex displacement/wobble.

Use at least two of these together for a stronger result.

## 2. Suggested target look

Recommended direction:
- Dark or saturated core colour.
- Bright cyan, electric blue, violet, or amber emission.
- High-contrast fresnel rim.
- Slowly moving energy pattern.
- Subtle wobble, not enough to make the target hard to aim at.

Make sure the target remains readable against both bright windows and dark floors.

## 3. Shader Graph setup

1. Create a URP Lit Shader Graph or Unlit Shader Graph.
2. Name it `SG_EnergyTarget`.
3. Create a material named `MAT_EnergyTarget`.
4. Assign the material to the target prefab.
5. Expose properties so colour and animation can be tuned without editing the graph.

Suggested exposed properties:

| Property | Type | Example starting value |
|---|---|---|
| `CoreColor` | Color | Deep blue |
| `RimColor` | Color | Cyan |
| `EmissionStrength` | Float | 2–5 |
| `NoiseScale` | Float | 3 |
| `ScrollSpeed` | Vector2 | (0.1, 0.2) |
| `NoiseContrast` | Float | 1.5 |
| `WobbleAmount` | Float | 0.02–0.06 |
| `WobbleSpeed` | Float | 1–2 |

Values are tuning starting points, not fixed specifications.

## 4. Scrolling noise

Suggested node flow:
1. Read UV.
2. Multiply UV by `NoiseScale`.
3. Add `Time` multiplied by `ScrollSpeed`.
4. Feed the result into a Simple Noise or sampled noise texture.
5. Use the noise to blend `CoreColor` and a brighter energy colour.
6. Feed the result into Base Color or Unlit Color.
7. Multiply the energy colour by `EmissionStrength` and connect it to Emission.

If using a texture, use a seamless noise texture and set wrap mode to Repeat.

## 5. Fresnel rim

Suggested node flow:
1. Add a Fresnel Effect node.
2. Expose a power/falloff control if desired.
3. Multiply Fresnel output by `RimColor`.
4. Multiply by `EmissionStrength`.
5. Add it to the energy colour.
6. Connect to Emission.

The rim should reinforce the silhouette without washing out the entire sphere.

## 6. Vertex wobble (optional)

For a subtle animated surface:
1. Use Position in Object space.
2. Feed scaled position into a time-driven sine/noise function.
3. Use the result to create a small displacement along the normal.
4. Multiply by `WobbleAmount`.
5. Add the displacement to the original vertex position.
6. Connect to Vertex Position.

Keep displacement small. Excessive wobble can make the collider feel disconnected from the visible target.

## 7. Animation options

Prefer Shader Graph time-based animation for simple scrolling and pulsing:
- No per-frame C# material updates required.
- Avoid creating a new material instance for every target.
- Expose values for quick tuning.

If C# must change material properties at runtime, use a `MaterialPropertyBlock` where supported rather than instantiating many unique materials.

## 8. Hit VFX

Create a prefab named `VFX_TargetBurst`:
- Short particle lifetime.
- One bright central burst.
- A few outward-moving sparks.
- Optional expanding ring.
- Additive or emissive look, but avoid excessive transparency.
- Keep particle count modest for mobile.

On target hit:
1. Instantiate the VFX at the target's world position.
2. Play immediately.
3. Destroy the VFX object after its particle lifetime, or use a self-cleaning effect script.

## 9. Projectile VFX

Recommended:
- Small glowing projectile mesh.
- Short Trail Renderer or particle trail.
- Brief muzzle flash if time allows.

Do not make the trail so long or bright that it obscures the target or camera view.

## 10. Visual quality checklist

- [ ] Target material is generated by Shader Graph.
- [ ] Graph includes scrolling noise, fresnel, or vertex displacement.
- [ ] Emission is visible on a physical phone.
- [ ] Target silhouette remains readable in a bright room.
- [ ] Animation is smooth and not distracting.
- [ ] Collider matches the visible target sufficiently.
- [ ] Hit burst plays once per target.
- [ ] VFX objects clean themselves up.
- [ ] Screenshot of the graph is captured for submission.
